# לוגיקת הקרקעה וכשירות מטוסים

## כלל ההחלטה

המערכת מחליטה על סטטוס מטוס לפי חומרת הממצאים הפתוחים:

| חומרה | סטטוס | פעולה נדרשת |
|--------|--------|-------------|
| **S1** - Safety Critical | 🔴 **מושבת (Grounded)** | השבתה מיידית עד לתיקון |
| **S2** - Mission Critical | 🟠 **מוגבל (Degraded)** | טיסה מותנית בהגבלות |
| **S3** - Deferred | 🟡 **כשיר עם הערה** | ניתן לטוס, מעקב נדרש |
| **S4** - Informational | 🟢 **כשיר (Ready)** | ללא מגבלות |

## הלוגיקה בקוד

```typescript
// FlightDossierContext.tsx - getFleetReadiness()
const hasS1 = tailFindings.some(f => f.severity === 'S1');
const hasS2 = tailFindings.some(f => f.severity === 'S2');

if (hasS1) {
  status = 'grounded';   // מושבת
} else if (hasS2) {
  status = 'degraded';   // מוגבל  
} else {
  status = 'ready';      // מוכן
}
```

## איך נקבעת החומרה?

1. **כללים פעילים** - כל כלל מגדיר חומרה (S1-S4) בעת יצירתו
2. **ניתוח אוטומטי** - המערכת מנתחת נתוני קופסה שחורה ומייצרת ממצאים
3. **Backtest** - לפני הפעלת כלל, מריצים בדיקה על נתונים היסטוריים

## דוגמאות לחומרות

### S1 - השבתה מיידית
- לחץ הידראולי מתחת ל-2800 PSI
- טמפרטורת מנוע מעל 850°C
- עומס G מעל 9.5

### S2 - הגבלות טיסה
- מהירות נחיתה מעל 165 קשר
- חריגות קלות בפרמטרי מנוע
- סימני בלאי מואצים

### S3 - מעקב
- מגמות עולות בטמפרטורה
- פרמטרים קרובים לסף

### S4 - ידיעה
- נתונים סטטיסטיים
- מידע לתחזוקה מונעת

## הוספת כלל חדש

1. **יצירת כלל** - דרך אשף יצירת הכלל
2. **הגדרת תנאים** - פרמטר, מפעיל, ערך סף
3. **קביעת חומרה** - S1-S4 לפי מטריצת סיכון
4. **Backtest** - בדיקה על נתונים אמיתיים
5. **אישור** - Draft → Review → Active

## תרשים זרימה

```

     ↓
S2? → מוגבל (כתום)
     ↓

```
